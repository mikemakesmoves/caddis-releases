# Downloads linked from caddis.app

This branch holds files the Caddis website links to. App builds live in the version releases.

- `plugin-kit/Caddis-Plugin-Kit.zip`: the Caddis Plugin Kit (SDK guide, example plugins and the Rust crate). See https://www.caddis.app/developers
- `plugins/vari/*.cadplugin`: free plugins by VARI (https://varimusic.com): Blinker, Filler, Image Dust and Pixel Sorter. Double-click a .cadplugin to install it in Caddis.
